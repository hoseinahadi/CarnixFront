# P4 UI delivery

## Profile ecosystem
- Persistent garage with vehicle, year, plate and mileage.
- Notification inbox with unread state and deep links.
- Support ticket list, creation, conversation and closing.
- Wallet route completes the existing profile navigation.

## Mechanics ecosystem
- Searchable/filterable directory, mechanic profile and service coverage.
- Appointment request flow and customer dashboard with cancellation.
- Booking actions create profile notifications.

## Symptom checker
- Five-step vehicle/system/symptom/severity/result wizard.
- Rule-based probable causes, urgency guidance, related parts and mechanic actions.

All P4 data is served by the authenticated ASP.NET API and persisted in SQL Server. Public mechanic and diagnostic catalogs are also database-backed.
